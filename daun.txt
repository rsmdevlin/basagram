Ты работаешь над моим проектом web-messenger и должен использовать локально клонированный исходный код Telegram Desktop как подробный UI/UX reference.

Главная цель: полностью изучить локальный репозиторий Telegram Desktop — структуру UI, компоненты, стили, темы, цвета, размеры, состояния, иконки, анимации, переходы, TGS/Lottie-анимации и UX-поведение — а затем профессионально реализовать аналогичный по уровню качества Telegram-like интерфейс в моем WEB-мессенджере.

1. СНАЧАЛА ОПРЕДЕЛИ ПРАВИЛЬНЫЕ ПУТИ

Не делай никаких предположений о расположении файлов.

Перед чтением файлов обязательно:

Выведи текущую рабочую директорию.
Найди реальную директорию моего web-messenger.
Найди реальную директорию локального tdesktop.
Сохрани абсолютные пути и используй только их.

На Windows используй PowerShell-команды вроде:

Get-Location

Get-ChildItem "C:\Users\myteg\Desktop" -Directory -Recurse -Depth 2 |
  Where-Object { $_.Name -eq "tdesktop" -or $_.Name -eq "web-messenger" } |
  Select-Object FullName

После обнаружения путей назначь их логически:

TDESKTOP_ROOT=<реальный абсолютный путь к tdesktop>
WEB_MESSENGER_ROOT=<реальный абсолютный путь к web-messenger>

НИКОГДА больше не пытайся читать путь, которого не существует.

Если Read сообщает File does not exist, не продолжай угадывать путь. Сначала найди файл через Get-ChildItem, Select-String, rg, fd или аналогичный поиск.

5. TGS / LOTTIE — ОБЯЗАТЕЛЬНО

Я хочу, чтобы ты умел исследовать .tgs.

.tgs — это Telegram Animated Sticker / Lottie JSON, обычно сжатый gzip.

Когда находишь .tgs, не говори, что формат неизвестен.

На Windows можешь:

Get-ChildItem <TDESKTOP_ROOT> -Recurse -Filter *.tgs

Для анализа содержимого распаковывай его во временную директорию, не изменяя оригинал.

Можно использовать Python:

import gzip
import json

src = r"C:\path\animation.tgs"

with gzip.open(src, "rt", encoding="utf-8") as f:
    data = json.load(f)

print(json.dumps(data, ensure_ascii=False, indent=2)[:20000])

Из TGS анализируй:

fr — framerate;
ip / op — animation range;
w / h;
layers;
transforms;
opacity;
scale;
position;
path animations;
easing/keyframes;
duration;
loop behavior.

Если анимация подходит для web, реализуй ее через:

lottie-web, если это настоящая Lottie-анимация;
CSS;
SVG;
Web Animations API;
Framer Motion;
React animation tools,

выбирая наиболее подходящий вариант.

Не конвертируй все TGS механически. Сначала выясни, для чего конкретная анимация используется в Telegram.
