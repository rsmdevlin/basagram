# 15. OPTIMISTIC UI

Сообщения должны появляться мгновенно через optimistic UI.

Используй:

```text
clientMessageId
serverMessageId
```

Сценарий:

```text
user sends message
↓
temporary message appears immediately
↓
server receives message
↓
server confirms
↓
temporary ID reconciled
↓
realtime event propagated
```

Если отправка провалилась:

* показать failed state;
* дать retry;
* не потерять текст.

WebRTC → calls
